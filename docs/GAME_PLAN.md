# 바다의 왕 (King of the Abyss) — 게임 기획서

**장르:** 2D 횡스크롤 해양 생존/성장 어드벤처
**플랫폼:** 모바일 웹 (PWA) — 세로 or 가로 모드, 터치 전용
**레퍼런스:** Shark Universe (성장/진화 루프), Hungry Shark Evolution (포만감 압박), Feed and Grow: Fish (티어 포식)
**핵심 한 줄:** 작은 리프 샤크로 시작해 수천 마리를 먹어치우고, 새로운 상어로 진화하며 심해의 왕좌까지 내려간다.

---

## 1. 설계 원칙 (왜 이렇게 만드는가)

| 원칙 | 결정 | 이유 |
|---|---|---|
| 3D 포기, 2D 벡터 | Canvas 2D + 도형 기반 절차적 렌더링 (스프라이트 에셋 0개) | 에셋 제작/토큰 비용 제거. 물고기 1종 추가 = 데이터 1줄 + 색상 팔레트 |
| 입력 2개로 제한 | 드래그 조준 + 부스트 버튼. 공격 버튼 없음 (접촉 시 자동 포식) | 모바일에서 버튼 3개 이상은 한 손 조작 불가 |
| 티어(Tier) 단일 규칙 | 모든 생물에 티어 1~10. `내 티어 >= 상대 티어` → 먹는다 / `상대 > 내 티어` → 맞는다 | "먹을 수 있나?"를 색/크기만 보고 0.2초에 판단 가능. 물고기 종류를 무한히 늘려도 규칙이 안 늘어남 |
| 성장을 2축으로 분리 | 런 내 성장(세션) ↔ 메타 성장(영구) | 한 판만 해도 성장의 쾌감, 계속 해야 할 이유도 동시에 확보 |
| 실시간 대기 없음 | 알 부화는 "시간"이 아니라 "런에서 먹은 양"으로 진행 | 접속 안 하면 못 자라는 구조 = 이탈. 플레이가 곧 진행 |

## 2. 코어 게임 루프

```
스테이지 진입
   ↓
작은 물고기 포식 → 성장 게이지 / 포만감 / 진주 획득
   ↓
성장 단계 상승 → 티어 +1 → 상위 물고기가 먹이로 전환 (해금의 쾌감)
   ↓
포만감 압박 (계속 먹지 않으면 체력 감소) → 멈출 수 없게 만듦
   ↓
보스 조우 → 격파
   ↓
[런 종료] 진주 + 상어알 + 알 성장치 정산
   ↓
메타 화면: 능력치 업그레이드 / 알 부화 / 상어 교체
   ↓
다음 스테이지 (더 깊고, 더 어둡고, 더 큰 것들)
```

**세션 길이 목표:** 1런 = 4~7분. 첫 플레이 3분 내에 "첫 성장 + 첫 알"을 반드시 경험시킨다.

## 3. 티어 시스템 (게임의 심장)

모든 생물은 `tier: 1~10`을 가진다.

| 관계 | 결과 |
|---|---|
| 내 티어 > 상대 티어 | 접촉 즉시 포식. 포만감·성장·진주 획득 |
| 내 티어 == 상대 티어 | 상호 데미지. 물어서 HP를 깎아야 포식 가능 |
| 내 티어 < 상대 티어 | 피격. 티어 차이만큼 데미지 ↑ |
| 특수 플래그 | `shell`(부스트로만 파괴), `toxic`(먹으면 중독), `shock`(접촉 피해, 포식 불가) |

**시각 규칙 (UI 없이 판단하게 만드는 장치)**
- 먹을 수 있음 → 외곽선 없음, 채도 높은 색
- 동급 → 노란 외곽선 + 미세한 맥동
- 못 먹음(위험) → 붉은 외곽선 + 접근 시 화면 테두리 비네트 붉어짐

## 4. 성장 — 2축 구조

### 4-1. 런 내 성장 (Session Growth)
- 성장 게이지 0 → 100 도달 시 **진화 단계 +1** (런 내 최대 +2단계)
- 효과: 티어 +1, 크기 ×1.25, 최대 HP +20%, 흡입 반경 +15%
- 획득량: `성장치 = 먹이 티어 ^ 1.6`
  - T1 ≈ 1 / T2 ≈ 3 / T3 ≈ 6 / T4 ≈ 10 / T5 ≈ 15
  - → T3 상어가 1단계 성장하려면 잡어 100마리 **또는** 동급 15마리. 양쪽 플레이스타일 모두 성립
- 피격으로 성장 게이지는 감소하지 않음(스트레스 방지), 단 진화 단계는 사망 시 초기화

### 4-2. 메타 성장 (영구)

**능력치 업그레이드 — 5종 × 5레벨**

| 능력치 | 효과 /레벨 | 비용 (Lv n) |
|---|---|---|
| 턱 (Bite) | 데미지 +15% | 150 × 2^(n-1) 진주 |
| 지느러미 (Fin) | 이동속도 +8% | 동일 |
| 체력 (Vitality) | 최대 HP +12% | 동일 |
| 폐 (Lung) | 부스트 지속 +20% | 동일 |
| 감각 (Sense) | 흡입 반경 +25%, 암흑 시야 +20% | 동일 |

**상어알 / 부화 (핵심 수집 요소)**
- 획득 경로: 보스 첫 격파 1개 / 스테이지 숨겨진 보물 3개 / 일일 미션
- 부화 방식: **실시간 대기 없음.** 알을 "부화 슬롯"에 넣으면 런에서 먹은 포만감의 20%가 알에 축적 → 100%에서 부화
- 중복 알 → 해당 상어 **각성 레벨 +1** (기본 스탯 +5%, 최대 +5)

## 6. 스테이지 구성 (6개)

각 스테이지는 자유 탐험형 오픈 구역 (월드 약 6000 × 2500px). 클리어 조건 = ① 목표 티어 도달 ② 보스 격파.
**3성 조건:** 보스 격파 / 피격 3회 이하 / 숨겨진 보물 3개 발견.

### 스테이지 1 — 햇살 연안 ☀️
- 수심 0~30m, 밝은 청록. 적정 티어 T3
- **먹이:** 멸치(T1·무리), 새우(T1), 흰동가리(T1·도주), 해마(T1), 고등어(T2·무리도주), 전갱이(T2·무리), 복어(T2·`toxic`), 불가사리(T2·정적), 농어(T3·도주), 가오리(T3), 게(T3·`shell`), 바다거북(T3·`shell`)
- **위험:** 해파리(`shock`), 어선 그물(접촉 시 2초 속박)
- **보스:** 거대 바라쿠다 (T4, HP 600)
- 포만감 소모 ×1.0 — 튜토리얼 구간

### 스테이지 2 — 산호 정원 🪸
- 수심 30~80m, 색채 폭발. 적정 티어 T4
- **먹이:** 비늘돔(T2), 나비고기(T2), 청줄놀래기(T2), 쏠배감펭(T3·`toxic`), 돌돔(T3), 오징어(T4·먹물로 시야 차단), 곰치 치어(T4·추격), 상어 치어(T5·추격), 대왕조개(T5·`shell`·고득점)
- **위험:** 성게(정적 가시), 말미잘(끌어당김), 좁은 산호 통로(압사 위험)
- **보스:** 대왕 곰치 (T6, HP 900) — 굴에 숨어 기습, 위치 예측 플레이
- 포만감 ×1.1

### 스테이지 3 — 난파선 해구 🚢
- 수심 80~250m, 어둡고 좁음. 적정 티어 T5
- **먹이:** 정어리(T3·대규모 무리), 노랑가오리(T3), 아귀(T4·유인등으로 유혹), 붕장어(T4), 참치(T5·초고속 도주, 부스트 필수), 황새치(T5·돌진 반격), 귀상어(T6·추격), 청새리상어(T6·추격)
- **위험:** 기뢰(폭발), 낚시줄, **암흑** — 시야 반경 제한(감각 업그레이드로 완화)
- **보스:** 무법자 백상아리 (T7, HP 1200)
- 포만감 ×1.2

### 스테이지 4 — 빙하 해역 🧊
- 수심 0~150m, 창백한 푸른색 + 유빙 천장. 적정 티어 T6
- **먹이:** 청어(T4·무리), 대구(T4), 연어(T5), 왕게(T5·`shell`), 바다표범(T6·민첩 도주), 펭귄(T6·도주), 바다코끼리(T7·탱커 추격), 레오파드바다표범(T7·추격)
- **위험:** 유빙 장애물, **냉수대**(포만감 소모 ×1.6), 쇄빙선 프로펠러(즉사급)
- **보스:** 범고래 알파 (T8, HP 1600) — 음파 기절 + 수면 돌진 콤보

### 스테이지 5 — 심해 열수구 🌋
- 수심 1000~4000m, 암흑 + 발광. 적정 티어 T7
- **먹이:** 발광 플랑크톤(T5·무리), 심해새우(T5), 풍선장어(T6), 도끼고기(T6), 흡혈오징어(T7), 그린란드상어(T7), 산갈치(T8), 심해 만타(T8)
- **위험:** 열수 분출(주기적 화상), 압력 지대(HP 지속 감소), **발광체 주변만 시야 확보**
- **보스:** 크라켄 (T9, HP 2200) — 촉수 8개를 개별 파괴해야 본체 노출
- 포만감 ×1.4

### 스테이지 6 — 왕좌의 해구 👑 (엔드게임)
- 적정 티어 T8
- **먹이:** 전 스테이지 **엘리트 변종** (티어 +1, 전원 공격적, 체력 ×2)
- **위험:** 소용돌이, 고대 유적 함정
- **보스:** 메갈로돈 (T10, HP 3000) — 3페이즈 + 엔딩 연출 → **바다의 왕** 칭호

## 7. 전투 / 수치 설계

**플레이어 수치**
```
최대 HP      = 100 × (1 + 0.15 × (상어티어 - 3)) × (1 + 0.12 × 체력레벨)
기본 속도    = 상어별 180~280 px/s × (1 + 0.08 × 지느러미레벨)
물기 데미지  = 10 × (1 + 0.15 × 턱레벨) × 상어 배수
흡입 반경    = 크기 × 1.2 × (1 + 0.25 × 감각레벨)   ← 이 반경 안의 하위 티어는 자동 흡입
```

**포만감 (Hunger) — 압박 장치**
```
최대 100, 초당 1.4 × 스테이지배수 감소
포만감 0 → 초당 최대 HP의 3% 감소
포식 1마리 회복량 = 먹이티어 × 4
```
→ 스테이지 1에서 T1 잡어만 먹으면 약 3초에 1마리는 먹어야 유지. "멈추면 죽는다"는 리듬 확보.

**부스트 (유일한 액션 버튼)**
```
스태미나 100 / 사용 시 초당 35 소모 / 미사용 시 초당 18 회복
속도 ×2.2, 충돌 데미지 = 물기 ×2.5 + 0.8초 스턴
용도: ① 추격·도주 ② shell 파괴 ③ 상위 티어 적 스턴 후 탈출 ④ 보스 경직 유발
```

**피격**
```
상위 티어 접촉 지속 피해 = (적티어 - 내티어) × 8 /초
피격 시 0.8초 무적 + 넉백 (연속 사망 방지)
```

**보스전 설계 (3페이즈 공통 골격)**

| 페이즈 | HP 구간 | 패턴 |
|---|---|---|
| 1 | 100~66% | 돌진 (0.7초 붉은 예고선) |
| 2 | 66~33% | 돌진 + **잡어 무리 소환** |
| 3 | 33~0% | 돌진 + 소환 + 광역기 (소용돌이/음파) |

- **약점 창(窓):** 돌진 직후 1.5초 경직 → 이 타이밍에 물면 데미지 ×2. 보스전이 "회피 후 반격" 리듬이 된다
- **소환 패턴이 디자인의 핵:** 보스가 소환한 잡어를 플레이어가 먹어서 포만감·HP를 회복한다. 즉 소환은 위협이면서 동시에 생명줄 → 장기 보스전에서 포만감 고갈로 억울하게 죽는 일을 방지

## 8. 조작 (모바일 최적화)

```
┌─────────────────────────────────┐
│ ❤️████░░  🍖███████░  👑T4  💎1,240│  ← HUD (상단, 최소화)
│                                 │
│                                 │
│          🦈                     │
│                                 │
│                                 │
│  ◉                        [ 🚀 ]│  ← 좌: 플로팅 조이스틱 / 우: 부스트
└─────────────────────────────────┘
```

- **이동:** 화면 왼쪽 절반 어디든 터치 → 그 지점에 조이스틱 생성, 드래그 방향으로 유영. 손가락을 떼면 관성으로 감속
- **포식:** 버튼 없음. 흡입 반경에 들어온 하위 티어는 자동 섭취
- **부스트:** 오른쪽 하단 고정 버튼 (반경 72px, 엄지 도달 범위 내)
- **성장 연출:** 진화 시 0.4초 슬로모션 + 화면 전체 파동 + 크기 확대 → 성장을 "느끼게" 만드는 핵심 피드백
- 세로 모드 기준 설계, 가로 모드는 시야 확대 보너스

## 9. 아트 / 사운드 방향

- **스타일:** 플랫 벡터 + 2~3색 그라디언트. 모든 생물은 Canvas Path(타원 + 삼각 지느러미 + 꼬리 베지에)로 **절차적 생성**
- **생물 1종 정의 = 데이터 1줄:** `{ id, name, tier, bodyColor, finColor, bodyRatio, behavior, flags }` → 물고기 50종을 에셋 없이 구현
- **애니메이션:** 꼬리 사인파 흔들림(속도 비례), 몸체 미세 스케일 펄스. 프레임 애니메이션 0장
- **배경:** 3레이어 패럴랙스 (원경 수중광 / 중경 암초 실루엣 / 근경 부유물 파티클)
- **사운드:** 효과음 8종 + 스테이지별 앰비언트 1개 (포식 '뽁', 부스트 '쉬익', 피격, 성장 '웅—', 보스 등장, UI)

## 11. 개발 단계

| 단계 | 범위 | 검증 기준 |
|---|---|---|
| **Phase 1 — 데모** | 스테이지 1, 상어 1종, 물고기 8종, 런 내 성장, 포만감, 부스트, 보스 1체, 결과 화면 | 폰 브라우저에서 60fps로 4분 플레이 → 성장 2단계 + 보스 격파까지 가능 |
| Phase 2 — 메타 | 진주/업그레이드/알 부화/상어 2종, localStorage 저장 | 앱 재진입 시 진행도 유지, 업그레이드 체감 |
| Phase 3 — 콘텐츠 | 스테이지 2~4, 물고기 30종, 상어 6종, 보스 4체 | 3성 시스템 동작, 스테이지당 5분 내 클리어 |
| Phase 4 — 완성 | 스테이지 5~6, 메갈로돈, 엔딩, 미션, 사운드, PWA 설치 | 신규 유저가 튜토리얼 없이 1런 완주 |

**Phase 1 (데모) 기술 스펙**
- 단일 HTML 파일 + Canvas 2D, 외부 의존성 0
- 고정 timestep 루프 (`dt = 1/60`, 누적 보정), 렌더는 requestAnimationFrame
- 객체 풀링 (물고기 200마리 + 파티클 300개 사전 할당, GC 스파이크 방지)
- DPR 상한 2 (저가 안드로이드 발열 방지)
- 공간 분할: 256px 균일 그리드 → 충돌 판정 O(n) 유지
- 물고기 정의는 `FISH` 배열로 분리 → 종 추가가 데이터 추가로 끝나는 구조

## 12. 열려 있는 결정 사항

1. **진주 획득 속도 vs 업그레이드 비용** — Phase 2에서 실측 후 조정 (목표: 1런 = 업그레이드 0.5~1레벨)
2. **수익화** — 현재 기획에서 제외. 넣는다면 광고 리워드(부활 1회/진주 2배)가 이 루프와 가장 덜 충돌
3. **멀티플레이** — 제외 권장. 같은 노력으로 스테이지 3개를 더 만드는 게 체감 가치가 큼
4. **세로 vs 가로 고정** — 데모에서 양쪽 테스트 후 결정

## 부록. 코어 데모 구현 노트 (`demo/index.html`)

데모는 Phase 1 보다 더 작은 **코어만** 구현한다 — 보스와 메타 성장은 빠졌다.
조작감과 코어 루프의 재미를 먼저 판단하는 것이 목적이다.

**구현된 것:** 이동 · 티어 포식 · 흡입 · 런 내 성장(4단계) · 포만감 · 부스트 ·
동급 전투(물기) · 껍질(부스트 필요) · 독(복어) · 감전(해파리) · 결과 화면

**빠진 것:** 보스, 진주/업그레이드/알 부화, 스테이지 2~6, 사운드, 저장

### 기획값과 달라진 부분 (실측으로 조정)

| 항목 | 기획 | 데모 | 이유 |
|---|---|---|---|
| 시작 티어 | T3 | **T2** | 포식 조건이 `내 티어 > 상대 티어`라 T1 로 시작하면 먹을 수 있는 대상이 공집합이 된다 |
| 진화 단계 | — | T2→T3→T4→T5 (4단계) | 1회 플레이에서 성장 전체 호를 보여주기 위함 |
| 월드 크기 | 6000 × 2500 | **3200 × 1700** | 세로 390×844 뷰포트가 원안의 3%만 비춰 화면이 텅 비었다 |
| 개체 밀도 | 명시 없음 | 활성 사각형 내 **170마리** | 화면 평균 30~40마리에서 "바다가 살아있다"는 느낌이 나온다 |
| 회피 반경 | 명시 없음 | 150px (기획 의도 270) | 270px 는 세로 화면 높이의 1/3 이라 플레이어 주변이 통째로 비었다 |

### 렌더링에서 배운 것

- **생물 피치는 ±32°로 제한해야 한다.** 속도 벡터를 그대로 각도로 쓰면 수직으로
  헤엄치는 물고기가 "세워둔 알약"으로 보인다. 횡스크롤 2D의 표준 처리
- **몸통 비율은 가로:세로 ≈ 2.4:1.** 1.2:1 이면 물고기가 아니라 달걀이다
- **채도를 올려야 수중 배경에서 분리된다.** 회청색 계열은 파란 물속에서 사라진다.
  청록 / 노랑 / 올리브 / 보라 / 주황처럼 배경과 색상환에서 떨어진 색을 쓴다
- **위험 비네트는 최대 알파 0.2.** 0.42 는 화면 전체를 보라색으로 덮는다
- 스폰은 원형 링이 아니라 **뷰포트 사각형 기준**이어야 한다. 세로 화면은
  가로 195px / 세로 422px 로 비대칭이라 원형 링은 가로 방향 개체를 화면 밖 360px 에 만든다

### 아직 사람이 확인해야 하는 것

자동 테스트(먹이 추적 오토파일럿)로 검증한 것은 **동작**이지 **재미**가 아니다.
다음은 직접 플레이로만 판단할 수 있다:

1. **성장 속도** — 오토파일럿 기준 75초에 최종 단계 도달. 사람은 더 느리겠지만
   런 목표(4~7분)보다 빠를 가능성이 높다. 임계값(30/72/150) 조정 필요 여부
2. **포만감 압박의 강도** — 1.2/초가 쫓기는 느낌인지, 성가신 느낌인지
3. **부스트 쓸 일이 충분한지** — 현재 용도는 추격 / 게 껍질 / 포식자 밀어내기 3가지
4. **동급 전투(물기)가 재미있는지** — 아니면 그냥 번거롭기만 한지
