## 1. 오늘 밤 한 것

### Q1 · 중간에 나가기 + 버그

| 항목 | 내용 |
|---|---|
| **⏸ 일시정지 버튼** | 오른쪽 위. 계속하기 / 처음부터 / 기지로 / 소리 |
| 중간에 나가면 | **이번 판 진주·부화 진행·클리어 전부 없음** (말한 대로). 실수 방지로 **두 번 눌러야** 나간다. 메뉴에 "진주 N개가 사라져요" 표시 |
| 자동 일시정지 | 앱을 내리거나 탭을 바꾸면 멈추고 BGM 도 멈춘다. 돌아오면 일시정지 화면에서 기다린다 |
| 데스크톱 | `Esc` / `P` 로 일시정지 |
| 정산 화면 | 죽음 → **[다시 도전]** [기지로] / 클리어 → **[다음 해역 ▶]** [한 번 더] [기지로] / 다음 해역을 못 가면 이유 표시 ("기본 티어 3 이상 상어 필요") |
| 기지 → 타이틀 | 기지 왼쪽 위 ‹ 버튼 |
| 마지막 해역 클리어 | "👑 바다의 왕!" + "더 깊은 바다는 지금 만드는 중" |
| 🐞 B1 | 잠긴 해역으로 출발되던 것 → 상어를 바꿔 해역이 잠기면 갈 수 있는 곳으로 자동 이동 + 출발 직전 한 번 더 확인 |
| 🐞 B2 | 새 해역이 열려도 선택이 안 되던 것 → 처음 클리어하면 다음 해역이 자동 선택 |

### Q2 · 지도 + 상태창

**바다 지도** (기지의 해역 카드 목록을 대체 — 기지 "바다 지도" 타일 또는 "바다로 ▶")
- 위가 수면, 아래로 갈수록 깊고 어두워진다. 노드 사이 물색이 해역 색으로 바뀐다
- 각 노드: 보스 그림 동그라미 · 이름 · 수심 · `클리어 ✓` / `도전!` / 🔒
- 깬 길은 금색 실선, 아직 못 간 길은 점선
- 아래 **"준비 중"** 3곳: 🧊 빙하 해역 · 🌋 심해 열수구 · 👑 왕좌의 해구 (기획서 스테이지 4~6)
- 누르면 아래 정보판: 설명 · 보스 · 도감 n/m종 · 필요 티어 · 최고 기록 · **이 해역의 위험 장치** · 잠긴 이유
- 가로 화면에서는 정보판이 오른쪽 기둥으로 간다

**상태창 (왼쪽 위)**
- 판 투명도 0.82 → **0.42** (바다가 비친다)
- 글씨 11.5 → **14px**, 막대 15 → **19px**, 막대 위에 **숫자** (체력 100, 포만감 85)
- 대신 글씨 그림자를 진하게 — 밝은 배경에서도 안 묻힌다
- 체력 25% · 포만감 20 아래면 **막대 테두리가 빨갛게 깜빡**
- 티어 숫자 16 → 21px, 먹은 물고기 10.5 → 13px, 아래 성장바 5 → 8px

### Q3 · 물고기 도감 + 누적 카운트

- 기지 **"📖 물고기 도감"** 타일 → 해역별 3열 카드
- 위에 요약 3칸: **지금까지 먹은 물고기 총 수 · 발견한 종류 n/29 · 쓰러뜨린 보스 n/3**
- 카드: 그림 · 이름 · `×먹은 수` · 티어 · 메달. **안 먹어본 종은 검은 실루엣 + ???**
- 카드를 누르면 상세: 큰 그림 · 먹이 규칙 한 마디 (🛡️ 껍질 / ☠️ 독 / ⚡ 못 먹음…) · **아이용 한 줄 설명** · 다음 메달까지 몇 마리
- 런 중 **처음 먹으면 "새 물고기 발견!" 배너** + 진주 보너스 (티어 × 5)
- 종마다 **🥉🥈🥇 메달** — 티어 1~3: 10/40/100마리, 티어 4+: 3/10/30마리. 메달 따면 진주 보너스
- 해파리·성게·기뢰처럼 못 먹는 것은 "닿아봤다"로 등록
- 정산 화면에 "도감 새 물고기 +n종"
- **그림을 새로 안 그렸다** — 게임이 쓰는 그리기 함수를 작은 캔버스에 그대로 돌린다. 스프라이트가 있으면 스프라이트, 없으면 도형

### Q4 · 해역별 고유 장치 + 추가하기 쉬운 구조

| 해역 | 장치 | 동작 |
|---|---|---|
| ☀️ 햇살 연안 | 🕸️ **어선 그물** | 수면에서 늘어진 그물 4개. 걸리면 거의 못 움직이고 **BOOST 연타**로 탈출 (6번 ≈ 0.7초). 안 눌러도 4초면 풀림 |
| 🪸 산호 정원 | 🦑 **오징어 먹물** | 오징어에게 다가가면 먹물을 뿜고 달아난다. 먹물 속은 화면이 어두워진다 |
| ⚓ 난파선 해구 | 💣 **기뢰 폭발** | 닿으면 펑 — 플레이어 피해 + 주변 물고기 **기절**(먹을 기회). **보스가 기뢰를 들이받으면 보스 −90 + 휘청** → 기뢰 쪽으로 유인하는 전략 |
| ⚓ 난파선 해구 | 🏮 **아귀 불빛** | 어둠 위에 불빛만 보인다. 기뢰 경고등도 어둠 속에서 깜빡 |

- 해역에 들어가면 이름 + 장치 설명이 화면 가운데 3초 뜬다
- **구조**: `HAZARDS` 에 항목 하나 + 해역 데이터에 `hazards:['키']` 한 줄이면 끝.
  지도 정보판·입장 안내·도감 섹션·정산 "다음 해역" 버튼은 `STAGES` 를 읽어 저절로 생긴다.
  새 해역은 `STAGES` 에 한 블록 넣고 `SOON` 에서 지우면 지도에 바로 나타난다

## 4. 성장·재미 추가 기획 (Q3 "더 기획해봐")

8살 기준으로 **"모으기 · 자랑하기 · 깜짝 놀라기"** 세 가지가 가장 잘 먹힌다고 보고 골랐다.
★ = 아트 없이 가능.

### A. 바로 효과 큰 것

| 아이디어 | 내용 | 왜 | 크기 |
|---|---|---|---|
| ★ **황금 물고기** | 아주 가끔(1~2%) 반짝이는 황금 변종이 나온다. 먹으면 진주 ×10 + 도감에 황금 칸 따로 | "봤어?!" 하는 깜짝 순간. 도감 수집욕을 한 번 더 자극 | 반나절 |
| ★ **먹기 콤보** | 2초 안에 연달아 먹으면 `3 콤보!` → 콤보가 길수록 진주 배수 | 멸치 떼에 돌진하는 맛이 숫자로 보인다. 즉각적 재미 | 반나절 |
| ★ **해역 도감 완성 보상** | 한 해역의 물고기를 다 찾으면 상어알 or 진주 대량 + 지도 노드에 📖 배지 | 도감에 "끝"을 만들어준다 | 2시간 |
| ★ **별 3개** | ★ 보스 / ★★ 해역 미션 / ★★★ 숨은 보물 3개 또는 시간 안 클리어. 지도 노드에 별 표시 | 깬 해역을 다시 할 이유. **미션 내용은 아이와 같이 정하기** | 하루 |

### B. 성장감을 늘리는 것

| 아이디어 | 내용 |
|---|---|
| ★ **상어 레벨** | 그 상어로 먹은 수가 쌓이면 상어 Lv.1→10. 레벨마다 아주 작은 보너스(체력 +2% 등). 상어 카드에 Lv 표시 → "내 톱상어 Lv.7" |
| ★ **칭호** | 도감·기록 연동 — "멸치 사냥꾼"(멸치 100), "기뢰 해체반"(보스를 기뢰로 3번), "바다의 왕"(전부 클리어). 기지 상단에 지금 칭호 |
| ★ **숨은 보물 상자** | 해역마다 고정 위치 3곳 (해초 사이·산호 밑·난파선 안). 하나는 BOOST 로 깨야 함. 넓은 맵을 돌아다닐 이유 |
| **상어 꾸미기** | 진주로 모자·선글라스·색 바꾸기. 진주 쓸 곳이 업그레이드뿐인 문제 해결. 아트 필요 (작은 소품 몇 장) |
| ★ **알 고르기** | 부화기에 넣을 상어를 고른다 |

### C. 다음 해역 (지도의 "준비 중" 3곳) — 장치 구조를 그대로 쓰는 설계

| 해역 | 고유 장치 아이디어 | 필요 상어 |
|---|---|---|
| 🧊 빙하 해역 | **유빙 천장**(위로 못 감) · **냉수대**(그 안에서 포만감 2배로 빨리 닳음, 색으로 표시) | 청상아리(기본 티어 4) — 지금 쓸 곳 없는 상어에 이유가 생긴다 |
| 🌋 심해 열수구 | **열수 분출**(주기적으로 뿜음, 예고 거품) · **발광 플랑크톤 주변만 보임** | 기본 티어 5 상어 (새 상어 필요) |
| 👑 왕좌의 해구 | **소용돌이**(끌려감, BOOST 로 탈출) · 전 해역 엘리트 변종 | 기본 티어 6 |

해역 하나 = 배경 1 + 물고기 8~10 + 보스 1 ≈ **그림 11장** + 장치 코드 1~2개.

### 추천 순서

1. 황금 물고기 + 먹기 콤보 (반나절, 아트 0) — 지금 도감과 바로 맞물린다
2. 별 3개 + 숨은 보물 (하루) — 아이와 미션 정한 뒤
3. 상어 레벨 + 칭호
4. 남은 아트 21장 (상어 12장 먼저)
5. 빙하 해역

## 부록 — 1차 검토 요약

- 코어 루프는 탄탄, 바깥 흐름이 비어 있었다: 런에서 나갈 길 없음 · 정산 후 다음 행동 안내 없음 · 3해역 클리어 후 할 것이 진주뿐
- 보스가 진화 3단계에 자동 소환 → 4단계(성체)는 보스전 중에만 됨
- 해금 사슬: 귀상어·청상아리가 진행에 필요 없음
- 한 판 길이 추정 3~4분 (성장 수치 30+72 로 계산), 물고기 50마리면 알 부화
- 능력치 전부 MAX = 진주 12,400 (≈ 40판)
