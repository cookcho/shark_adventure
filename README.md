# 바다의 왕 (King of the Abyss)

모바일 웹 기반 2D 해양 성장 어드벤처. 작은 치어로 시작해 먹고, 자라고, 더 큰 것을 먹어
결국 바다의 왕이 된다.

레퍼런스: Shark Universe (성장/진화 루프) · Hungry Shark Evolution (포만감 압박) ·
Feed and Grow: Fish (티어 포식)

---

## 현재 상태

| | |
|---|---|
| **기획서** | [`docs/GAME_PLAN.md`](docs/GAME_PLAN.md) — 상어 8종, 스테이지 6개, 물고기 50종, 보스 6체 전체 설계 |
| **데모** | [`demo/index.html`](demo/index.html) — 코어 루프 + 보스 + 메타 성장 |

**플레이 가능:** https://cookcho.github.io/shark_adventure/

구현된 루프: 기지에서 **해역**·상어 고르고 업그레이드 → 출발 → 먹고 자라기(4단계) →
진화 3단계에서 **보스** 등장 → 3페이즈 격파 → 정산(진주·상어알) → 다음 해역 해금 → 기지로.
진행도는 localStorage 에 저장된다.

**해역 3곳** (햇살 연안 / 산호 정원 / 난파선 해구), **보스 3체**, **상어 4종**, **물고기 29종**, 사운드.

**아직 없는 것:** 해역 4~6, 보스 3체, 상어 4종, 미션·3성 평가, 숨겨진 보물.

## 실행

의존성 없음. 파일 하나다.

```bash
# 로컬
open demo/index.html

# 폰에서 테스트 (같은 Wi-Fi)
python3 -m http.server 8000
# → http://<PC의 IP>:8000/demo/
```

`?debug=1` 을 붙이면 `window.__G` 로 내부 상태가 노출된다 (자동 테스트용).

## 핵심 규칙 — 외곽선 색

| 색 | 의미 |
|---|---|
| 없음 | 먹이. 닿으면 먹힌다 |
| 노랑 | 동급. 물어서 체력을 깎아야 먹을 수 있다 |
| 하늘 | 껍질. 부스트로만 깨진다 |
| 빨강 | 포식자. 닿으면 피해를 입는다 |

모든 생물은 티어 1~10을 가지며, `내 티어 > 상대 티어`면 먹고 아니면 맞는다.
규칙이 하나라서 물고기 종류를 늘려도 복잡도가 늘지 않는다.

## 해역

| 해역 | 수심 | 필요 상어 | 보스 | 특징 |
|---|---|---|---|---|
| 햇살 연안 | 0~30m | 기본 티어 2 | 거대 바라쿠다 | 밝다. 수면 광선 |
| 산호 정원 | 30~80m | 기본 티어 3 | 대왕 곰치 | 독·가시. 포만감 ×1.1 |
| 난파선 해구 | 80~250m | 기본 티어 3 | 무법자 백상아리 | **어둡다 — 보이는 곳까지만 안전**. 포만감 ×1.2 |

**상어마다 시작 티어가 다르다.** 리프 샤크 2 / 톱상어·귀상어 3 / 청상아리 4.
깊은 해역은 더 높은 기본 티어를 요구하므로, 상어알 부화가 곧 다음 바다로 가는 열쇠다.
어두운 해역에서는 **감각 업그레이드가 시야 반경**이 된다 (귀상어는 ×1.35).

## 이미지 에셋

게임은 **이미지 없이 완전히 동작한다.** 모든 생물과 배경에 Canvas 절차적 렌더링이
폴백으로 들어 있고, 에셋이 없으면 네트워크 요청이 0건이다.

그림을 `demo/assets/` 에 넣고 `demo/index.html` 의 `ART` 객체에 등록하면 그 그림이 쓰인다.
로딩에 실패하면 경고 1줄을 남기고 조용히 Canvas 렌더링으로 돌아간다.
**이미지는 보이는 것만 바꾼다** — 충돌 판정, 속도, 성장 수치, 저장 데이터는 영향받지 않는다.

규격은 [`docs/ASSETS.md`](docs/ASSETS.md), 생성 프롬프트는
[`docs/ASSET_PROMPTS.md`](docs/ASSET_PROMPTS.md).

### 적용 현황 (22/53)

| 분류 | 상태 |
|---|---|
| 타이틀 배경 | ✅ |
| **해역 배경 3곳** | ✅ **전부 완료** |
| **보스 3체** | ✅ **전부 완료** |
| **햇살 연안 물고기 10종** | ✅ **전부 완료** |
| 리프 샤크 4단계 | ✅ |
| 산호 정원 물고기 | 상어 치어 ✅ · 나머지 10종 ⬜ |
| 난파선 해구 물고기 | ⬜ 10종 |
| 상어 3종 × 4단계 | ⬜ 12장 |

미적용 종은 Canvas 절차적 렌더링으로 그려지며, 스프라이트와 한 화면에 공존한다.

**기술 선택**
- Canvas 2D + 절차적 벡터 렌더링 — **스프라이트 에셋 0장.** 모든 생물이 Path(타원 + 지느러미 삼각형 + 베지에 꼬리)로 그려지고 꼬리 사인파로 애니메이션된다
- 물고기 1종 추가 = `FISH` 배열에 한 줄 (`{ id, name, tier, 색, 서식수심, behavior }`)
- 고정 timestep(1/60) 시뮬레이션 + `requestAnimationFrame` 렌더 분리
- DPR 상한 2 (저가 안드로이드 발열 방지)
